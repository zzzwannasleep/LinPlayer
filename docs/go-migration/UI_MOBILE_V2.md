# 手机端 UI · 第二版设计

> 2026-09-06。**这一版推翻第一版的视觉与动效,数据层与页面族不变。**
>
> 第一版(`UI_MOBILE.md`)的问题不在 token,在**构图**:色板、间距刻度、
> M3 emphasized 缓动那几样都是对的,但整个应用从头到尾只有一种版式 ——
> 一摞长得一样的横向轨道 + 直角卡片。那是**用 Compose 写出了网页的样子**。
>
> 旧的 `docs/mobile-drafts/` 与 `desktop-drafts.html` 一律**不再作为参考** ——
> 它们是 Web 技术下的产物,和 Compose 的能力不对齐(用户 2026-09-06 明确要求)。

## 0. 这一版到底改什么

按影响从大到小。**每一条都要能在截图里看出来** —— 看不出来的就不是设计改进。

| # | 改什么 | 为什么第一版不行 |
|---|---|---|
| 1 | **共享元素转场**(卡片海报 → 详情页大图,同一张图连续飞过去) | 第一版是「整页右滑入 + 淡入」,和任何一个网页路由动画没区别。这是安卓原生**独有**、Web 做不出来的东西,不用它就等于白换栈 |
| 2 | **折叠大标题**(滚动时 44sp 大标题收成 20sp 居中小标题) | 第一版每页顶部都是一条固定 56dp 的小标题条,信息密度低而且毫无层次 |
| 3 | **海报取色染整页**(详情页背景、按钮、进度条都跟着当前这张海报走) | 第一版全站一个蓝(`acc = 5B8CFF`)。媒体应用的性格来自内容,不来自品牌色 |
| 4 | **形状有变化**(M3 Expressive:胶囊、圆角矩形、squircle 三种并存,按下时形状会变) | 第一版所有东西都是 `RoundedCornerShape(12)`,一眼看过去是一张网格纸 |
| 5 | **首页三段式**(沉浸大图 → 继续观看横滑 → 分库瀑布),不是六条一样的轨道 | 第一版首页是 hero + 六条同构轨道,第三条往下用户已经不知道自己在看什么 |
| 6 | **底栏用 M3 `NavigationBar` 的动画指示丸** | 第一版是手搓的三个图标,选中态只是变色 |
| 7 | **触感反馈**(切 Tab / 长按卡片 / 拖进度条到片头片尾) | 一个都没有 |
| 8 | **列表进场错峰**(每项晚 24ms 上浮 12dp) | 第一版是整块一起淡入,读起来像截图刷新 |

**不改的**:色板语义、间距刻度、duration/easing token、页面族与路由、数据加载结构
(各块并发、不设屏障)。那几样第一版是对的,推翻它们只会引入回归。

## 1. 设计语言

### 1.1 形状 —— 从「一个圆角」到「三种形状各有分工」

| 形状 | 值 | 用在哪 | 为什么 |
|---|---|---|---|
| `pill` | 999 | 芯片、Tab 指示丸、主按钮、评分角标 | 胶囊读作「可点、会变」 |
| `card` | 16 | 海报卡、面板、弹窗、列表卡 | 比第一版的 12 大一档 —— 12 在 6.7 寸屏上偏硬 |
| `squircle` | 连续曲率圆角(`RoundedPolygon` 近似),半径 20 | **只给三处**:媒体库入口、榜单前三名、设置头像 | 它是 M3 Expressive 的签名形状。到处用就不签名了 |
| `none` | 0 | 沉浸大图、视频层 | |

**按下时形状会变**:`pill` 按下 → 半径掉到 card(胶囊被"压扁"),弹起用
`LpSpring.bouncy()` 弹回。这一条只给主按钮和 Tab,别处按下只做 96% 缩放。

### 1.2 颜色 —— 内容染色

保留 `LpColors` 全套语义 token。**新增一层**:`LocalAccent`。

- 默认 = `Lp.colors.acc`
- 进详情页 / 播放页时,从当前海报取主色(核心层已经在做,见 `emby.imageColor`;
  取不到就退回默认),经**可读性钳位**后覆盖 `LocalAccent`
- 钳位规则:与 `bg` 的对比度必须 ≥ 3.0,否则往亮度方向推,推到头就放弃用默认

☠ **只染强调色,不染背景**。整页跟着海报变背景 = 深色片一片黑、亮色片一片白,
而字的颜色是固定的 —— 那是「好看的截图,不能用的应用」。

### 1.3 字阶

第一版散着写 `fontSize = 24.sp / 16.sp / 13.sp / 11.sp`。这一版定五档,全站只有这五档:

| 名字 | 大小 / 字重 | 用在哪 |
|---|---|---|
| `Display` | 44sp / Black | 折叠大标题展开态、榜单名次数字 |
| `Title` | 22sp / Bold | 详情页片名、页面小标题 |
| `Section` | 17sp / SemiBold | 轨道标题、分组头 |
| `Body` | 14sp / Normal | 卡片标题、正文 |
| `Meta` | 12sp / Normal / fg2 | 年份、时长、集号、说明 |

## 2. 动效

### 2.1 共享元素(这一版的核心)

`SharedTransitionLayout` 包住 `NavHost`,卡片海报与详情页大图共享
`rememberSharedContentState(key = "poster-${item.id}")`。

- 转场时长 `T.T7`(350ms),缓动 `LpEasing.emphasized`
- **只共享海报**。标题也共享的话字号从 14sp 跳到 22sp 会看到明显的字重跳变
- 详情页返回时反向播放,**不是**淡出

☠ key 必须带 item id。写成固定串 `"poster"` 的话,同屏两张卡都能匹配上,
转场会从**错误的那张**飞出去 —— 而且只在滚动过之后才复现。

### 2.2 折叠大标题

`TopAppBarDefaults.exitUntilCollapsedScrollBehavior`。展开 152dp / 收起 56dp。
标题从左下 `Display` 插值到居中 `Title`,插值走 `emphasized`,不是线性。

### 2.3 进场错峰

列表每项 `delay(index.coerceAtMost(8) * 24ms)` 后上浮 12dp + 淡入。
**封顶第 9 项** —— 不封顶的话第 40 项要等 960ms,那不是动效是卡顿。

### 2.4 触感

| 动作 | 反馈 |
|---|---|
| 切 Tab | `HapticFeedbackConstants.SEGMENT_TICK` |
| 长按卡片出菜单 | `LONG_PRESS` |
| 拖进度条经过片头/片尾边界 | `SEGMENT_FREQUENT_TICK` |
| 播放/暂停 | `CONTEXT_CLICK` |

☠ 别给「点击」加通用触感 —— 全应用每次点都震一下,用户会去系统设置里把整个应用的触感关掉。

## 4.5 草稿图怎么出

草稿是**真 Compose**,不是画的图,也不是网页原型 ——
上一版的草稿是 Web 原型,照着它写出来的 Compose 就长着网页的样子。
共享元素、折叠大标题、squircle、错峰进场,这几样在 Web 原型里根本表达不出来,
于是也就没人去做。**草稿用什么技术写,成品就会长成什么样。**

代码在 `apps/android/.../ui/drafts/Drafts.kt`。出图:

```bash
export ANDROID_HOME="$LOCALAPPDATA/Android/Sdk"
(cd apps/android && ./gradlew assembleDebug)
adb install -r apps/android/app/build/outputs/apk/debug/app-x86_64-debug.apk
for n in 1 2 3 4 5 6; do
  adb shell am force-stop xyz.linplayer.app.debug
  adb shell am start -n xyz.linplayer.app.debug/xyz.linplayer.app.MainActivity -e lp_page "drafts:$n"
  sleep 4 && adb exec-out screencap -p > "draft-$n.png"
done
```

☠ **包名带 `.debug` 后缀**(`applicationIdSuffix`)。发给 `xyz.linplayer.app` 的
`am start` 会打到 release 包上 —— 而它可能是几天前装的那个,于是你截到的是旧界面,
还以为是新代码没生效。栽过一次。

☠ 截图**不进仓库**:2.7MB 的 PNG,而且上面这几行命令随时能重出。

## 5. 判据

**不看「编译过了」,看截图。** 每一页出两张:深色 + 浅色。

1. 首页大图**顶到状态栏**,没有一条横在中间的顶栏
2. 从首页卡片点进详情页,海报是**飞过去**的,不是新页面淡入
3. 详情页的主按钮颜色**跟着海报变**,换一部片颜色跟着变
4. 媒体库页滚动时大标题**收成小标题**,不是整条不动
5. 集详情页有「上一集 / 下一集」
6. 播放页调亮度/音量时**屏幕上有反馈**
7. 列表进场是**错峰**的,不是整块一起亮
8. 深浅色各出一遍,浅色下没有任何一处对比度不足
